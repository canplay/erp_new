# erp_new 部署文档

> 基于 K8s（Rancher）+ Helm 的生产部署指南

## 1. 部署架构

### 1.1 环境规划

| 环境 | 地址 | 说明 |
|---|---|---|
| 生产环境 | `https://admin.example.com:8901` | 仅 HTTPS |
| 集群命名空间 | `myai-prod` | K8s 命名空间 |
| 镜像仓库 | `harbor.example.com:8003/erp` | Harbor 私有仓库 |

### 1.2 镜像 Tag 格式

`YYYYMMDDHHMM`（纯数字 12 位）

### 1.3 部署组件

| 组件 | 镜像 | 说明 |
|---|---|---|
| 后端 API | `erp/api-gateway` | API Gateway |
| 后端服务 | `erp/<service-name>` | 22 个微服务 |
| 前端 admin | `erp/admin` | 管理后台（平台运营） |
| 前端 tenant | `erp/tenant` | 单位业务端 |
| 前端 ops | `erp/ops` | 运营面板 |
| 前端 social | `erp/social` | 社交端 |

## 2. 前置条件

## 3. 本地开发部署

### 3.1 docker-compose 启动

```bash
# 1. 配置环境变量
cp .env.example .env

# 2. 启动基础设施（PostgreSQL + Redis + Meilisearch）
podman compose -f deploy/docker-compose.yml up -d

# 3. 初始化数据库（自动 via docker-compose volumes）
# schema.sql 自动挂载到 /docker-entrypoint-initdb.d/

# 4. 编译后端
cd Backend
# 注意: sqlx prepare 需要可达的 PostgreSQL（编译期校验 SQL）
# 本地 compose 已起 PG 时: export DATABASE_URL=postgres://postgres:***@localhost:5432/erp_new
cargo sqlx prepare --workspace
cargo build --workspace

# 5. 启动前端
cd Frontend
pnpm install
pnpm --filter myai-admin dev    # http://localhost:9000
```

## 4. 生产构建

### 4.1 后端镜像构建

```bash
podman build -t erp/api-gateway:latest \
  --build-arg SERVICE_NAME=api-gateway \
  --build-arg HTTP_PORT=8090 \
  -f Backend/Dockerfile .
```

### 4.2 前端镜像构建

```bash
cd Frontend
pnpm install
pnpm --filter myai-admin build
podman build -t erp/admin:latest -f Frontend/apps/admin/Dockerfile Frontend/apps/admin
```

### 4.3 推送 Harbor

```bash
podman push --tls-verify=false erp/api-gateway:latest \
  harbor.example.com:8003/erp/api-gateway:latest
```

## 5. Helm 部署

### 5.1 部署结构

```
deploy/
├── docker-compose.yml              # 本地开发编排
└── helm/myai/                      # Helm Chart (Chart: erp-new v0.3.0)
    ├── Chart.yaml
    ├── values.yaml                 # 默认 values
    ├── values-prod.yaml            # 生产环境
    ├── ENV_MAPPING.md
    ├── README.md
    ├── secrets.example.yaml
    ├── fix-tags.py
    └── templates/
        ├── _helpers.tpl
        ├── configmap.yaml
        ├── deployment.yaml
        ├── infrastructure.yaml
        ├── ingress.yaml
        ├── secret.yaml
        └── service.yaml
```

### 5.2 Helm 升级

```bash
helm upgrade --install erp-new ./deploy/helm/myai \
  -n myai-prod \
  -f deploy/helm/myai/values-prod.yaml \
  --set image.tag=$(date +%Y%m%d%H%M)
```

### 5.3 验证 Helm

```bash
helm lint ./deploy/helm/myai/
helm lint ./deploy/helm/myai/ -f ./deploy/helm/myai/values-prod.yaml
```

## 7. 环境变量

### 7.1 后端运行时（根目录 .env）

| 变量 | 说明 |
|---|---|
| DATABASE_URL | PostgreSQL 连接串 |
| REDIS_URL | Redis 连接串 |
| JWT_SECRET | JWT 签名密钥（≥32字符） |
| JWT_ISSUER | JWT 签发者 |
| JWT_AUDIENCE | JWT 受众 |
| API_GATEWAY_HTTP_PORT | 网关端口（默认8090） |
| RATE_LIMIT_MAX | 限流最大请求数（默认1000） |
| RATE_LIMIT_WINDOW | 限流窗口秒数（默认60） |
| RATE_LIMIT_BURST | 突发容量（默认100） |
| CORS_ALLOWED_ORIGINS | CORS 允许来源（默认*） |
| *_SERVICE_HTTP_PORT | 各服务 HTTP 端口 |
| *_SERVICE_GRPC_PORT | 各服务 gRPC 端口 |

## 8. 数据库迁移

### 8.1 全量初始化

```bash
psql -h <host> -U postgres -d erp_new -f Backend/sql/schema.sql
```

> ⚠️ **已知问题（v0.9.0 发现）**: schema.sql 2880 行处的 `migrate_service_tables` 函数含嵌套 dollar-quote，psql 整文件执行时其后的建表语句（pay/tenants/socialops/audit 等 35 张表）会被静默跳过。**规避方法**：执行 schema.sql 后补跑一次（幂等），并手动预建依赖：

```bash
# 补齐被跳过的表（幂等，可重复执行）
psql -h <host> -U postgres -d erp_new -c "CREATE SCHEMA IF NOT EXISTS socialops"
psql -h <host> -U postgres -d erp_new -c "CREATE SEQUENCE IF NOT EXISTS gw_login_devices_id_seq; CREATE SEQUENCE IF NOT EXISTS gw_ip_whitelist_id_seq; CREATE SEQUENCE IF NOT EXISTS gw_sensitive_audit_id_seq"
psql -h <host> -U postgres -d erp_new -f Backend/sql/schema.sql   # 重跑补齐
```

### 8.2 重置数据库（开发用，危险！）

```bash
psql -h <host> -U postgres -d erp_new -f Backend/sql/999_reset.sql
```

> ⚠️ `999_reset.sql` 包含 DROP TABLE 语句，仅用于开发环境重置。

## 9. CI/CD

GitHub Actions 自动执行：
- **Backend**: `cargo fmt`, `clippy`, `cargo check`, `cargo test`（380 tests 基线）
- **Frontend**: `vue-tsc --noEmit`, `quasar build`
- **Helm**: `helm lint` 验证

> 注: CI 中 `cargo check/test` 依赖 sqlx 离线缓存（`Backend/.sqlx/`，320 个 query cache 已随仓库提交），无需数据库即可编译。

## 10. 故障排查

```bash
kubectl -n myai-prod describe pod <pod-name>
kubectl -n myai-prod exec -it <pod-name> -- /bin/sh
psql -h <host> -U postgres -d erp_new -c "SELECT COUNT(*) FROM users;"
```
