# erp_new 设计文档

> 基于 Rust + Vue 3 + Quasar 的全栈微服务管理平台

## 1. 项目概述

erp_new 是一套面向多业务场景的全栈微服务管理平台，采用 Rust gRPC 微服务架构，提供用户认证、权限管理、审计日志、即时通讯、内容管理、工作流、支付等核心能力。

### 1.1 技术栈

| 层 | 技术 |
|---|---|
| 后端框架 | Rust (Axum) + gRPC (Tonic) |
| 前端框架 | Vue 3.5 + Quasar 2 + Pinia + Vite |
| 数据库 | PostgreSQL（119 表） |
| 缓存 | Redis |
| 认证 | JWT Bearer |
| 部署 | Helm / docker-compose |
| 工程化 | pnpm workspaces + Turborepo |

## 6. 统一错误处理

所有微服务统一使用 `common::AppError` 和 `AppResult<T>`：

```rust
// 错误定义（crates/common/src/errors.rs）
pub enum AppError {
    NotFound(String),
    DatabaseError(String),
    ValidationError(String),
    Unauthorized,
    Forbidden,
    // ... 50+ variants
}

// 类型别名
pub type AppResult<T> = Result<T, AppError>;

// 服务使用示例
use common::{AppError, AppResult};

async fn get_user(id: i64) -> AppResult<User> {
    let user = repo.find(id).await
        .map_err(|e| AppError::DatabaseError(e.to_string()))?;
    Ok(user)
}
```

## 8. 安全配置

- JWT 密钥 ≥ 32 字符
- 数据库 SSL/TLS
- CORS 白名单
- Rate Limiting + Circuit Breaker
- 日志脱敏
