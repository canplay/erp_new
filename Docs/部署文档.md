# erp_new 部署文档

> 基于 K8s（Rancher）+ Helm 的生产部署指南

## 1. 部署架构

### 1.1 环境规划

| 环境 | 地址 | 说明 |
|---|---|---|
| 生产环境 | `https://admin.example.com:8901` | 仅 HTTPS |
| 集群命名空间 | `myai-prod` | K8s 命名空间 |
| 镜像仓库 | `harbor.example.com:8003/erp` | Harbor 私有仓库 |

### 1.2 镜像 Tag 格式

`YYYYMMDDHHMM`（纯数字 12 位）

### 1.3 部署组件

| 组件 | 镜像 | 说明 |
|---|---|---|
| 后端 API | `erp/api-gateway` | API Gateway |
| 后端服务 | `erp/<service-name>` | 22 个微服务 |
| 前端 admin | `erp/admin` | 管理后台（平台运营） |
| 前端 tenant | `erp/tenant` | 单位业务端 |
| 前端 ops | `erp/ops` | 运营面板（19 页面） |
| 前端 social | `erp/social` | 社交端（13 页面） |

## 2. 前置条件

### 2.1 工具要求

| 工具 | 版本 | 说明 |
|---|---|---|
| Rust | 1.85+ | 后端编译 |
| Node.js | 20+ | 前端编译 |
| pnpm | 11+ | 包管理 |
| Podman/Docker | 最新 | 容器构建 |
| kubectl | 最新 | K8s 管理 |
| Helm | v3+ | Chart 管理 |

### 2.2 基础设施

- K8s 集群（Rancher 管理）
- PostgreSQL 16+
- Redis 7+
- Harbor 镜像仓库
- （可选）Meilisearch 全文搜索

## 3. 本地开发部署

### 3.1 docker-compose 启动

```bash
# 1. 配置环境变量
cp .env.example .env
cp deploy/scripts/.env.example deploy/scripts/.env

# 2. 启动基础设施
podman compose -f deploy/docker-compose.yml up -d

# 3. 初始化数据库
psql -h localhost -U postgres -d erp_new -f Backend/sql/000_init.sql
psql -h localhost -U postgres -d erp_new -f Backend/sql/001_saas_core.up.sql
psql -h localhost -U postgres -d erp_new -f Backend/sql/001_tenant_id_columns.sql
psql -h localhost -U postgres -d erp_new -f Backend/sql/002_missing_indexes.sql
psql -h localhost -U postgres -d erp_new -f Backend/sql/003_subscription_tables.sql
psql -h localhost -U postgres -d erp_new -f Backend/sql/gw_tables.sql

# 4. 编译后端
cd Backend
cargo sqlx prepare --workspace
cargo build --workspace

# 5. 启动前端
cd Frontend
pnpm install
pnpm --filter myai-admin dev
```

## 4. 生产构建

### 4.1 后端镜像构建

```bash
# 构建所有后端服务镜像
bash deploy/scripts/build-backend.sh

# 构建单个服务
podman build -t erp/api-gateway:latest \
  --build-arg SERVICE_NAME=api-gateway \
  --build-arg HTTP_PORT=8090 \
  -f Backend/Dockerfile .
```

### 4.2 前端镜像构建

```bash
bash deploy/scripts/build-frontend.sh
```

### 4.3 推送 Harbor

```bash
bash deploy/scripts/push.sh <组件名>
```

## 5. Helm 部署

### 5.1 部署结构

```
deploy/
├── docker-compose.yml          # 本地开发编排
├── helm/myai/                  # Helm Chart
│   ├── Chart.yaml
│   ├── values.yaml             # 默认 values
│   ├── values-dev.yaml         # 开发环境
│   ├── values-prod.yaml        # 生产环境
│   ├── values-prod-harbor.yaml # Harbor 生产环境
│   ├── values-services.yaml    # 服务配置
│   ├── values-common.yaml      # 公共配置
│   ├── values-infrastructure.yaml # 基础设施配置
│   └── templates/              # K8s 资源模板
└── scripts/
    ├── build-backend.sh        # 后端构建
    ├── build-frontend.sh       # 前端构建
    ├── deploy-backend.sh       # 后端部署
    ├── deploy-frontend.sh      # 前端部署
    ├── build-and-deploy.sh     # 全栈流水线
    └── lib/                    # 共享函数库
```

### 5.2 部署命令

```bash
# 全栈部署
KUBECONFIG=rancher.kubeconfig bash deploy/scripts/build-and-deploy.sh

# 仅部署后端
KUBECONFIG=rancher.kubeconfig bash deploy/scripts/deploy-backend.sh

# 仅部署前端
KUBECONFIG=rancher.kubeconfig bash deploy/scripts/deploy-frontend.sh

# 自动 tag 部署（使用 Harbor 最新 tag）
bash deploy/scripts/helm-deploy-auto-tags.sh
```

### 5.3 Helm 升级

```bash
helm upgrade --install myai ./deploy/helm/myai \
  -n myai-prod \
  -f deploy/helm/myai/values-prod-harbor.yaml \
  --set image.tag=<tag>
```

## 7. 环境变量

### 7.1 后端运行时（根目录 .env）

| 变量 | 说明 |
|---|---|
| DATABASE_URL | PostgreSQL 连接串 |
| REDIS_URL | Redis 连接串 |
| JWT_SECRET | JWT 签名密钥（≥32字符） |
| JWT_ISSUER | JWT 签发者 |
| JWT_AUDIENCE | JWT 受众 |
| API_GATEWAY_HTTP_PORT | 网关端口 |
| *_SERVICE_HTTP_PORT | 各服务 HTTP 端口 |
| *_SERVICE_GRPC_PORT | 各服务 gRPC 端口 |

### 7.2 构建部署（deploy/scripts/.env）

| 变量 | 说明 |
|---|---|
| HARBOR_URL | Harbor 仓库地址 |
| HARBOR_PROJECT | Harbor 项目名 |
| HARBOR_USER | Harbor 用户名 |
| HARBOR_PASS | Harbor 密码 |
| RANCHER_URL | Rancher 地址 |
| RANCHER_USER | Rancher 用户名 |
| RANCHER_PASS | Rancher 密码 |
| NAMESPACE | K8s 命名空间 |
