# erp_new 部署文档

> 基于 K8s（Rancher）+ Helm 的生产部署指南

## 1. 部署架构

### 1.1 环境规划

| 环境 | 地址 | 说明 |
|---|---|---|
| 生产环境 | `https://admin.example.com:8901` | 仅 HTTPS |
| 集群命名空间 | `myai-prod` | K8s 命名空间 |
| 镜像仓库 | `harbor.example.com:8003/erp` | Harbor 私有仓库 |

### 1.2 镜像 Tag 格式

`YYYYMMDDHHMM`（纯数字 12 位）

### 1.3 部署组件

| 组件 | 镜像 | 说明 |
|---|---|---|
| 后端 API | `erp/api-gateway` | API Gateway |
| 后端服务 | `erp/<service-name>` | 22 个微服务 |
| 前端 admin | `erp/admin` | 管理后台（平台运营） |
| 前端 tenant | `erp/tenant` | 单位业务端 |
| 前端 ops | `erp/ops` | 运营面板 |
| 前端 social | `erp/social` | 社交端 |

## 2. 前置条件

### 2.1 工具要求

| 工具 | 版本 | 说明 |
|---|---|---|
| Rust | 1.85+ | 后端编译 |
| Node.js | 20+ | 前端编译 |
| pnpm | 11+ | 包管理 |
| Podman/Docker | 最新 | 容器构建 |
| kubectl | 最新 | K8s 管理 |
| Helm | v3+ | Chart 管理 |

### 2.2 基础设施

- K8s 集群（Rancher 管理）
- PostgreSQL 16+
- Redis 7+
- Harbor 镜像仓库
- （可选）Meilisearch 全文搜索

## 3. 本地开发部署

### 3.1 docker-compose 启动

```bash
# 1. 配置环境变量
cp .env.example .env

# 2. 启动基础设施（PostgreSQL + Redis）
podman compose -f deploy/docker-compose.yml up -d

# 3. 初始化数据库
psql -h localhost -U postgres -d erp_new -f Backend/sql/schema.sql

# 4. 编译后端
cd Backend
cargo sqlx prepare --workspace
cargo build --workspace

# 5. 启动前端
cd Frontend
pnpm install
pnpm --filter myai-admin dev
```

## 4. 生产构建

### 4.1 后端镜像构建

```bash
# 构建单个服务
podman build -t erp/api-gateway:latest \
  --build-arg SERVICE_NAME=api-gateway \
  --build-arg HTTP_PORT=8090 \
  -f Backend/Dockerfile .
```

### 4.2 前端镜像构建

```bash
cd Frontend
pnpm install
pnpm --filter myai-admin build
podman build -t erp/admin:latest -f Frontend/apps/admin/Dockerfile Frontend/apps/admin
```

### 4.3 推送 Harbor

```bash
podman push --tls-verify=false erp/api-gateway:latest harbor.example.com:8003/erp/api-gateway:latest
```

## 5. Helm 部署

### 5.1 部署结构

```
deploy/
├── docker-compose.yml              # 本地开发编排
└── helm/myai/                      # Helm Chart (Chart name: erp-new v0.3.0)
    ├── Chart.yaml
    ├── values.yaml                 # 默认 values
    ├── values-prod.yaml            # 生产环境
    ├── ENV_MAPPING.md
    ├── README.md
    ├── secrets.example.yaml
    ├── fix-tags.py
    └── templates/
        ├── _helpers.tpl
        ├── configmap.yaml
        ├── deployment.yaml
        ├── infrastructure.yaml
        ├── ingress.yaml
        ├── secret.yaml
        └── service.yaml
```

### 5.2 Helm 升级

```bash
helm upgrade --install erp-new ./deploy/helm/myai \
  -n myai-prod \
  -f deploy/helm/myai/values-prod.yaml \
  --set image.tag=<tag>
```

### 5.3 验证 Helm

```bash
helm lint ./deploy/helm/myai/
helm lint ./deploy/helm/myai/ -f ./deploy/helm/myai/values-prod.yaml
```

## 6. 验证部署

```bash
# 查看 Pod 状态
kubectl -n myai-prod get pods

# 查看服务日志
kubectl -n myai-prod logs -f deployment/api-gateway

# 查看 Helm 部署状态
helm status erp-new -n myai-prod

# 查看 Ingress
kubectl -n myai-prod get ingress
```

## 7. 环境变量

### 7.1 后端运行时（根目录 .env）

| 变量 | 说明 |
|---|---|
| DATABASE_URL | PostgreSQL 连接串 |
| REDIS_URL | Redis 连接串 |
| JWT_SECRET | JWT 签名密钥（≥32字符） |
| JWT_ISSUER | JWT 签发者 |
| JWT_AUDIENCE | JWT 受众 |
| API_GATEWAY_HTTP_PORT | 网关端口 |
| *_SERVICE_HTTP_PORT | 各服务 HTTP 端口 |
| *_SERVICE_GRPC_PORT | 各服务 gRPC 端口 |

## 8. 数据库迁移

### 8.1 全量初始化

```bash
psql -h <host> -U postgres -d erp_new -f Backend/sql/schema.sql
```

### 8.2 重置数据库（开发用，危险！）

```bash
psql -h <host> -U postgres -d erp_new -f Backend/sql/999_reset.sql
```

> ⚠️ `999_reset.sql` 包含 DROP TABLE 语句，仅用于开发环境重置。

## 9. 故障排查

```bash
# 查看 Pod 事件
kubectl -n myai-prod describe pod <pod-name>

# 进入 Pod 调试
kubectl -n myai-prod exec -it <pod-name> -- /bin/sh

# 查看数据库连接
psql -h <host> -U postgres -d erp_new -c "SELECT COUNT(*) FROM users;"
```
