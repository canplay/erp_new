# MyAI 前端待办清单

> 基于 Vue 3 + Quasar 的全栈微服务管理平台前端

## 1. 项目现状

### 1.1 应用结构

| 应用 | 框架 | 页面数 | 说明 |
|---|---|---|---|
| admin | Vue3 + Quasar | 87 | 管理后台 |
| ops | Vue3 + Quasar | - | 运营面板 |
| social | Vue3 + Quasar | - | 社交端 |

### 1.2 共享层

- `packages/shared` - 共享组件和工具

## 2. 待办事项

### 2.1 高优先级

- [ ] **路由治理**: 清理未在路由中注册的页面文件
- [ ] **组件复用**: 提取 admin/ops/social 共用组件到 `packages/shared`
- [ ] **类型安全**: 清理 TypeScript `any` 类型，使用具体类型替代
- [ ] **i18n 补全**: 硬编码中文词条下沉到 i18n 包

### 2.2 中优先级

- [ ] **性能优化**: 路由懒加载、组件按需引入、图片压缩
- [ ] **错误边界**: 统一错误处理组件
- [ ] **加载状态**: 统一 Loading 组件和 Skeleton
- [ ] **空状态**: 统一 EmptyState 组件

### 2.3 低优先级

- [ ] **主题切换**: 暗色模式支持
- [ ] **国际化**: 英文翻译补全
- [ ] **无障碍**: ARIA 标签和键盘导航

## 3. 页面清单（admin）

- `auth/login` - 登录页
- `auth/register` - 注册页
- `auth/forgot-password` - 忘记密码
- `auth/reset-password` - 重置密码
- `auth/confirm-email` - 邮箱确认

### 3.2 业务页面

- `dashboard` - 仪表盘
- `equipment` - 设备管理
- `daily-control` - 日管控
- `weekly-check` - 周排查
- `monthly-report` - 月调度
- `hidden-danger` - 隐患闭环
- `personnel` - 人员管理

### 3.3 系统管理

- `users` - 用户管理

- `tenants` - 租户管理
- `audit` - 审计日志
- `settings` - 系统设置

## 4. 技术债务

### 4.1 代码质量

- 部分页面使用 `:any` 类型
- 部分组件缺少 Props 类型定义
- 部分页面缺少错误处理

### 4.2 性能

- 部分大页面未做懒加载
- 部分图片未压缩
- 部分请求未做防抖/节流
