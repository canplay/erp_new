## 3. API 接口清单

### 3.1 认证相关

- `POST /api/auth/login` - 用户登录
- `POST /api/auth/register` - 用户注册
- `POST /api/auth/refresh` - 刷新 Token
- `POST /api/auth/logout` - 用户登出

### 3.2 用户管理

- `GET /api/users` - 用户列表
- `GET /api/users/:id` - 用户详情
- `POST /api/users` - 创建用户
- `PUT /api/users/:id` - 更新用户
- `DELETE /api/users/:id` - 删除用户

### 3.3 其他业务

- 详见各服务 OpenAPI 文档

## 4. 技术债务

### 4.1 代码质量

- 部分服务缺少单元测试
- 部分错误处理不够细致
- 部分日志格式不统一

### 4.2 性能

- 部分查询缺少索引
- 部分请求未做缓存
- 部分连接池配置未优化
