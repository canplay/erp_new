# MyAI 部署文档

> 基于 K8s（Rancher）+ Helm 的生产部署指南

## 1. 部署架构

### 1.1 环境规划

| 环境 | 地址 | 说明 |
|---|---|---|
| 生产环境 | `https://admin.100.100.100.100.example.com:8901` | 仅 HTTPS |
| 集群命名空间 | `myai-prod` | K8s 命名空间 |
| 镜像仓库 | `harbor.100.100.100.101.example.com:8003/myai` | Harbor 私有仓库 |

### 1.2 镜像 Tag 格式

`YYYYMMDDHHMM`（纯数字 12 位）

### 1.3 部署组件

| 组件 | 镜像 | 说明 |
|---|---|---|
| 后端 API | `myai/api-gateway` | API Gateway |
|| 后端服务 | `myai/<service-name>` | 22 个微服务（含 billing-service） |
|| 前端 admin | `myai/admin` | 管理后台（平台运营） |
|| 前端 tenant | `myai/tenant` | 单位业务端 |
| 前端 ops | `myai/ops` | 运营面板（19 页面） |
| 前端 social | `myai/social` | 社交端（13 页面） |

## 5. 环境变量配置

### 5.1 核心环境变量

| 变量名 | 必填 | 说明 |
|---|---|---|
| `DATABASE_URL` | 是 | PostgreSQL 连接字符串 |
| `REDIS_URL` | 是 | Redis 连接字符串 |
| `JWT_SECRET` | 是 | JWT 签名密钥（≥32字符） |

### 5.2 密钥管理

生产环境密钥通过 K8s Secret 注入：

```bash
# 创建 Secret
kubectl create secret generic myai-secrets \
  --from-literal JWT_SECRET="$(openssl rand -base64 48)" \
  --from-literal POSTGRES_PASSWORD="$(openssl rand -base64 24)" \
  --from-literal REDIS_URL="redis://redis-replication:6379/0" \
  -n myai-prod
```

## 8. 监控与告警

## 9. 故障排查

### 9.1 常见问题

| 问题 | 排查方法 |
|---|---|
| Pod 无法启动 | `kubectl describe pod <pod> -n myai-prod` |
| 服务无法访问 | `kubectl get svc -n myai-prod` |
| 数据库连接失败 | 检查 DATABASE_URL 和 Secret |
| gRPC 调用失败 | 检查服务发现配置 |

### 9.2 常用命令

```bash
# 查看 Pod 日志
kubectl logs -f <pod> -n myai-prod

# 进入 Pod 调试
kubectl exec -it <pod> -n myai-prod -- /bin/sh

# 查看 Service
kubectl get svc -n myai-prod

# 查看 Ingress
kubectl get ingress -n myai-prod
```

## 11. 多租户部署

### 11.1 共享部署（默认）

多租户共享同一 K8s 命名空间，通过 `tenant_id` 隔离：

```bash
# 部署到共享命名空间
helm upgrade myai ./Scripts/helm/myai \
  -n myai-prod \
  --set global.tenant.isolation=shared \
  --set global.tenant.sharedNamespace=myai-prod
```

### 11.2 专属部署（大客户）

为特定租户创建独立命名空间和数据库 Schema：

```bash
# 创建租户专属命名空间
kubectl create namespace myai-tenant-acme

# 初始化租户 Schema
psql -U postgres -d myai -f Backend/sql/000_init.sql \
  -v tenant_schema=tenant_acme

# 部署租户专属实例
helm upgrade myai-acme ./Scripts/helm/myai \
  -n myai-tenant-acme \
  --set global.tenant.isolation=dedicated \
  --set global.tenant.tenantId=acme \
  --set global.tenant.schemaName=tenant_acme
```

### 11.3 租户配额管理

|---|---|---|
